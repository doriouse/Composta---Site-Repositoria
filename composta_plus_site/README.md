# Composta+

Site interativo sobre compostagem.

## O que já está funcionando

- Landing page responsiva
- Quiz de perfil com recomendação
- Composteira virtual com camadas, dias, umidade, temperatura e decomposição
- Persistência automática com `localStorage`
- Busca “Posso colocar isso?”
- Impactômetro com kg, sacos evitados e composto estimado
- Sistema de XP
- Conquistas/desafios
- Laboratório de curiosidades
- Modal de conteúdos
- Jornada visual do resíduo
- Layout mobile/desktop
- Menu mobile
- Estrutura pronta para trocar textos, imagens e vídeos

## Como executar

Não precisa de backend para esta versão.

1. Extraia o projeto.
2. Abra `index.html` no navegador.

Para desenvolvimento, é recomendado usar o Live Server do VS Code.

## Onde personalizar

- `index.html`: textos, seções e estrutura.
- `css/style.css`: cores, tipografia, espaçamento e aparência.
- `js/app.js`: quiz, resíduos, XP, conquistas e lógica da composteira.
